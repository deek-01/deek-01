☕ Coffee Sales Dashboard in Excel
Welcome to my very first data analytics project! This interactive **Coffee Sales Dashboard** was created using **Microsoft Excel** as part of a guided project by YouTuber [Mo Chen](https://www.youtube.com/@MoChenExcel).

**About the Project**

The goal of this project was to transform raw coffee order data into meaningful business insights through visual storytelling.

### 📌 Key Features

- 📅 **Sales Trend Analysis:** Line chart showing total sales over time
- 🌍 **Country-wise Sales:** Bar chart comparing sales across countries
- 🧍 **Top Customers:** Highlighting the top 5 customers by sales
- 🎛 **Dynamic Filtering:** Timeline slicer, Roast Type, Product Size, and Loyalty Card filters
- 💡 **Fully Interactive Dashboard:** Designed for quick, actionable insights

## 📂 Project Components

- **Raw Data Sheets:** Orders, Customers, Products
- **Data Cleaning:** Removing blanks, correcting data types, and formatting
- **PivotTables & PivotCharts:** Used to summarize and visualize data
- **Dashboard Design:** Combined visuals into a user-friendly layout

## 🛠 Tools Used

- Microsoft Excel (PivotTables, Charts, Slicers)
- Power Pivot (Data Model)
